# Preston Hughes Music

Official country artist website. Static HTML and CSS, ready for GitHub Pages.

## Publish
Open repository Settings → Pages. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.

Website URL: https://chopper5786666.github.io/Preston-hughes-music/

Before launch, add verified Spotify, Apple Music, Instagram and TikTok URLs, and replace the sample contact email with an address you control.
